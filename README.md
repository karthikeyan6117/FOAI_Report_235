AI-Based Exam Duty and Laboratory Allocation System
Constraint Satisfaction and Search Algorithms project — Foundations of Artificial Intelligence

Team: Kaarthika S (2116240701221) · Karthikeyan A (2116240701235)

What it does
Assigns venues and invigilators to exam sessions as a CSP, then repairs the allocation after incidents (lab down, exam postponed, faculty on leave) with minimal changes.

Algorithms
AC-3 constraint propagation
Backtracking search with MRV, degree, LCV heuristics and forward checking
Min-conflicts local search with change penalty (repair)
Hill climbing on soft-constraint cost
Independent validator and infeasibility explanation
